## Brand & Style

This design system channels the refined, hyper-focused productivity paradigms of tools like Linear and Notion, adapted specifically for scheduling and appointment coordination. It treats appointments not as transient calendar alerts, but as structured, high-value commitments. 

The aesthetic marries rigorous minimalism with quiet tactile refinement. The interface deliberately pulls back decoration to foreground schedule density, status tracking, and chronological cadence. The visual tone is decisive, tranquil, and dependable—eliminating scheduling friction while evoking effortless command over time.

## Colors

The palette leverages a crisp, hyper-structured chromatic architecture built for quick status parsing and focused clarity.

- **Background & Canvas:** Built over `#f8fafc` (slate-50), providing a soft, non-reflective foundation that reduces eye strain over extended workflow sessions.
- **Surface & Cards:** Pure `#ffffff` rests atop the slate canvas, punctuated by razor-thin borders in `#e2e8f0` (slate-200) for structural isolation.
- **Primary Accent (`#4f46e5` / `#4338ca` hover):** Deep electric indigo commands direct focal actions: primary CTAs, active time-selection slots, and focused timeline states.
- **Semantic Status Signals:** 
  - **Confirmed:** Emerald (`#10b981` / text `#047857` / tint `#ecfdf5`) indicates finalized bookings and verified attendees.
  - **Pending:** Amber (`#f59e0b` / text `#b45309` / tint `#fffbeb`) highlights holds, unverified slots, and pending client confirmations.
  - **Cancelled / Critical:** Rose (`#f43f5e` / text `#be123c` / tint `#fff1f2`) explicitly calls out conflicts, cancellations, and drop-offs.
- **Text & Contrast:** Primary text is set in `#0f172a` (slate-900), secondary context in `#475569` (slate-600), and muted metadata in `#94a3b8` (slate-400).

## Typography

Inter serves as the single typographic workhorse across headline, body, and UI tiers. Its neutral geometric skeleton and tall x-height deliver immediate scanability in tight tabular data, booking calendars, and dense agenda views.

Tighter negative letter-spacing (`-0.025em` down to `-0.015em`) is systematically enforced across all titles and headers to give the interface a tailored, editorial precision reminiscent of modern product engineering tools. For metadata, timestamps, and status chips, `label-sm` utilizes uppercase tracking (`0.04em`) combined with medium/semibold weights to maintain legibility at glanceable micro-scales.

## Layout & Spacing

The layout model pairs a fluid, highly-disciplined 12-column grid for primary views with fixed-width contextual utilities (such as a 280px left rail for calendars/navigation and 380px contextual side-drawers for booking details).

Generous outer boundaries (`space-xl` and `margin`) establish expansive, breathable margins that offset dense scheduling grids. Element groupings maintain strict spatial relationships: `space-xs` (4px) binds related micro-elements (icons next to time stamps), `space-sm` (8px) separates form elements or internal card metadata, and `space-md` (16px) establishes standard internal container padding. 

On mobile devices (`< 768px`), multi-pane timeline columns condense into a single vertical stream, outer margins drop to `1rem`, and time-selection pills expand to full-width touch targets.

## Elevation & Depth

Visual hierarchy uses a refined hybrid approach: low-contrast borders combined with ultra-diffused, ambient multi-layer drop shadows. Avoid harsh, heavy drop-shadows.

- **Level 0 (Canvas):** Flat `#f8fafc`.
- **Level 1 (Cards, Appointments, Slots):** Pure `#ffffff` surface, 1px perimeter border in `#e2e8f0`, supported by a soft dual shadow: `0 1px 3px 0 rgba(15, 23, 42, 0.04), 0 1px 2px -1px rgba(15, 23, 42, 0.03)`.
- **Level 2 (Hovered Cards, Dropdowns, Datepickers):** Pure `#ffffff` surface, border in `#cbd5e1`, with elevated diffusion: `0 4px 6px -1px rgba(15, 23, 42, 0.06), 0 2px 4px -2px rgba(15, 23, 42, 0.04)`.
- **Level 3 (Modals, Sheet Drawers):** Border in `#cbd5e1`, supported by an expansive ambient blur: `0 20px 25px -5px rgba(15, 23, 42, 0.08), 0 8px 10px -6px rgba(15, 23, 42, 0.04)`.

## Shapes

The interface embraces a tailored rounded geometry that balances geometric structure with friendly accessibility. 

Base components—including input fields, buttons, and individual agenda list items—utilize standard `0.5rem` (8px) curvature. Larger layout containers, primary scheduling cards, and modal sheets scale to `rounded-xl` (1.5rem / 24px) or `rounded-lg` (1rem / 16px) to maintain a soft, modern contour against the background canvas. Micro-pills and status tags leverage full continuous pill radii (`9999px`) to create distinction between actionable cards and non-interactive status indicators.

## Components

### Buttons
- **Primary:** Background `#4f46e5`, text `#ffffff`, font weight `500`. Hover state `#4338ca`. Active state scales subtly (`scale(0.99)`). Focus ring: 2px offset with `rgba(79, 70, 229, 0.35)`.
- **Secondary:** Surface `#ffffff`, border 1px solid `#e2e8f0`, text `#0f172a`. Hover: surface `#f1f5f9`, border `#cbd5e1`.
- **Ghost / Subtle:** Transparent surface, text `#475569`. Hover: surface `#f1f5f9`, text `#0f172a`.

### Cards & Booking Blocks
- Structured on pure `#ffffff` backgrounds, bounded by 1px `#e2e8f0` borders and `rounded-xl` corners. 
- Timeline booking blocks include a 3px accent stroke down their left border corresponding to their status (Emerald for Confirmed, Amber for Pending, Rose for Cancelled, Indigo for Selected/In Progress).

### Status Chips & Badges
- Pill-shaped (`rounded-full`), padding `2px 8px`, typography `label-sm`.
- **Confirmed:** `#ecfdf5` background, `#047857` text, subtle `#a7f3d0` border.
- **Pending:** `#fffbeb` background, `#b45309` text, subtle `#fde68a` border.
- **Cancelled:** `#fff1f2` background, `#be123c` text, subtle `#fecdd3` border.

### Input Fields & Selectors
- Background `#ffffff`, border 1px solid `#cbd5e1`, radius `0.5rem`, typography `body-md`.
- Focus state switches border directly to `#4f46e5` with an accompanying glow: `box-shadow: 0 0 0 3px rgba(79, 70, 229, 0.12)`.
- Placeholder text in `#94a3b8`.

### Checkboxes & Radios
- Size 16px × 16px, border 1.5px solid `#cbd5e1`, radius 4px (checkbox) or circular (radio).
- Checked state: background `#4f46e5`, border `#4f46e5`, with a crisp white internal glyph.

### Time Slot Selectors (Product-Specific)
- Discrete grid units styled as secondary buttons: border 1px solid `#e2e8f0`, background `#ffffff`, radius `0.5rem`.
- Unavailable slots: `#f8fafc` background, text `#94a3b8`, cursor not-allowed, stripped border.
- Active/Selected slot: background `#4f46e5`, text `#ffffff`, border `#4f46e5`, shadow `0 2px 4px rgba(79, 70, 229, 0.2)`.
